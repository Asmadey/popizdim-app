# Прототип диаризации: speakrs (pyannote community-1, CoreML)

Фаза 1 из [`docs/plans/file-transcription.md`](../../docs/plans/file-transcription.md). Отдельный крейт, в сборку приложения не входит.

## Запуск

```bash
# 1. Веса (только данные, ~273 МБ): закреплённая ревизия, проверка SHA-256 / git-хеша
curl -sf "https://huggingface.co/api/models/avencera/speakrs-models/tree/67f963b6a1d94fcd4678948237b3cc8bd69bf1d8?recursive=true" -o models/.tree.json
python3 -I fetch_models.py models

# 2. Тестовые диалоги (macOS say + ffmpeg) с разметкой audio/*.truth.txt
python3 -I make_dialogue.py

# 3. Сборка и запуск в песочнице: без сети, без чтения домашней папки, чистое окружение
cargo fetch
./sandboxed.sh cargo build --release --offline
./sandboxed.sh target/release/diarize-speakrs-spike "$PWD/models" "$PWD/audio/ru3.wav" [ahc_threshold]

# 4. Сверка с разметкой
./sandboxed.sh target/release/diarize-speakrs-spike "$PWD/models" "$PWD/audio/ru3.wav" | python3 -I score.py audio/ru3.truth.txt
```

`models/`, `audio/` и `target/` не коммитятся (`.gitignore`).

## Результаты (2026-10-15, Apple Silicon, macOS 26.2)

| Запись                                       | Длина | Скорость | Найдено говорящих | Верно размечено реплик                |
| -------------------------------------------- | ----- | -------- | ----------------- | ------------------------------------- |
| `ru3` — Milena + две копии со сдвигом высоты | 37 с  | ×10      | 2 из 3            | 5 из 7 (C слита с A)                  |
| `en3` — Samantha, Daniel, Karen              | 27 с  | ×25      | 2 из 3            | 4 из 6 (Karen слита с Samantha)       |
| `ru3x8` — `ru3` восемь раз подряд            | 298 с | ×72–105  | 3 из 3            | 48 из 56 (половина реплик C ушла в A) |

- Границы реплик совпадают с разметкой с точностью до ~0,1 с.
- Загрузка моделей — 0,4–0,8 с.
- Пиковая память процесса — 1,3–2,0 ГБ.
- Порог AHC (0,3–0,6) на коротких записях результат не меняет; параметра «число говорящих» в speakrs 0.6 нет.
- Сборка: в песочнице за 18 с. Сам speakrs не выполняет код при сборке (`build.rs` нет), сеть только с фичей `online`, которая выключена.
- В приложении с `features = ["coreml"]` остаётся один `ort` (2.0.0-rc.12) — проверено через `cargo tree`, изменения откачены.

### Настоящая запись: `agora.mp4` (видео h264 + AAC 48 кГц моно, 14,5 мин)

Фактически говорит **один человек** (подтвердил пользователь).

| Порог AHC                    | Говорящих                  | Реплик | Скорость                 | Пик памяти |
| ---------------------------- | -------------------------- | ------ | ------------------------ | ---------- |
| 0,6 (по умолчанию), 0,4, 0,1 | 1                          | 145    | ×134 (6,5 с на 14,5 мин) | 1,7 ГБ     |
| 0,3 и 0,2                    | 2 (4,4 мин / 7,5 мин речи) | 178    | ×130                     | —          |

При пороге 0,3, если отбросить реплики короче 1 с, получается 18 блоков: «1» с 00:01 по 02:39, затем чередование, «0» с 10:59 до конца (14:27). Извлечение звука системным ffmpeg заняло 0,7 с.

Вывод: порог по умолчанию (0,6) верен — ложного деления нет. Порог 0,3 ложно делит одного человека на двоих. Снижать порог, чтобы «найти больше людей», нельзя; в приложении оставляем значение по умолчанию.

Не проверено: настоящая запись с несколькими людьми. На синтетике порог по умолчанию на коротких клипах сливал похожие голоса.

Синтетические голоса — упрощённый тест: копии одного голоса со сдвигом высоты различать труднее, чем разных людей. Нужна проверка на настоящей записи с несколькими людьми.
